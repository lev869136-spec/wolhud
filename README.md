# WOLHUD

Мультиплеерный шутер от первого лица в браузере — с 3D-меню в духе CS2 и
чистой low-poly графикой в стиле Standoff 2. Без сборки, без внешних ассетов:
графика, звук и «карта» генерируются кодом.

## Запуск

```bash
npm install
npm start
```

Открой `http://localhost:3000` (сервер слушает `0.0.0.0:3000`).

## Управление

| Клавиша | Действие |
| --- | --- |
| `WASD` | движение |
| Мышь | прицел |
| `ЛКМ` | огонь |
| `ПКМ` | прицеливание (у AWM — оптика) |
| `R` | перезарядка |
| `1 / 2 / 3` | автомат / пистолет / нож |
| `Shift` | бег |
| `Space` | прыжок |
| `Ctrl` | присед |
| `Tab` | таблица результатов |
| `Enter` | чат |
| `Esc` | пауза |

## Структура

```
server/            Node.js: Express (статика) + WebSocket (мультиплеер)
  index.js         HTTP + WS сервер, тик-цикл
  game.js          комнаты, игроки, авторитетный hitscan, урон/киллы/респаун
public/
  index.html       меню + HUD
  css/style.css
  js/config.js     общий конфиг (оружие, карта, спавны) — шарится с сервером
  js/main.js       точка входа, рендер-цикл, состояния меню/игра
  js/menu.js       3D-сцена главного меню (камера вращается вокруг бойца)
  js/game.js       геймплей: контроллер, коллизии, видмодель, HUD, интерполяция
  js/world.js      небо, свет, карта, персонажи, частицы
  js/weapons.js    low-poly модели оружия
  js/net.js        WebSocket-клиент
  js/audio.js      процедурные звуки (WebAudio)
  js/input.js      клавиатура + мышь + pointer lock
  vendor/          собранный three.js (ES-модуль)
```

## Как это работает

- **Мультиплеер**: WebSocket-сервер держит комнаты (до 8 игроков) и рассылает
  снапшоты состояния 15 раз в секунду. Движение клиент-авторитетное, попадания
  считает сервер (ray vs капсула игрока / AABB-мир), поэтому урон, киллы и
  хедшоты честные.
- **Графика**: `MeshStandardMaterial` с `flatShading` + контурные рёбра дают
  фасеточный «мобильный» вид, градиентное небо, мягкий туман и дрейфующая пыль.
- **3D-меню**: живая сцена — боец на контейнере, вокруг него медленно едет
  камера, как в CS2.
